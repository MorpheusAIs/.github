# .github

This repository contains the org-wide default community health files for MorpheusAIs. Repositories use these defaults only when they do not have their own copy; a repository's own file wins.

It also contains `profile/README.md`, the public organization profile.

| File | Purpose |
| --- | --- |
| `AGENTS.md` | Org-wide guide for AI coding agents |
| `CONTRIBUTING.md` | Default contribution workflow and PR rules |
| `SECURITY.md` | Private vulnerability reporting guidance |
| `SUPPORT.md` | Where to go for questions and non-security reports |
| `CODE_OF_CONDUCT.md` | Community code of conduct |
| `profile/README.md` | Public organization profile |
| Issue and PR templates | Default issue and pull request forms |
| Vulnerability report form | Private vulnerability report form |

Changes here are made by pull request into `main`.
