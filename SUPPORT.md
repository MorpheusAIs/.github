# Support

| Need | Where to go |
| --- | --- |
| Question or how-to | Org Discussions in a matching category |
| Idea | Org Discussions, Ideas category |
| Big proposal | Contracts & MRC Discussions category, then the MRC repository |
| Bug or feature request that is real work | Issues in the affected repository |
| Security issue | Private vulnerability reporting on the affected repository, or security@mor.org |
| Documentation | https://gitbook.mor.org, https://nodedocs.mor.org, https://apidocs.mor.org |
| Network status | https://active.mor.org |

Response target: 3 business days.

Maintainer coordination happens in private maintainer channels; anything decided is recorded on GitHub.
